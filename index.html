Backup

Fazer Backup

Baixe um backup único e completo de todos os dados persistentes do sistema, incluindo senhas, usuários, técnicos, configurações, equipamentos, estoque, clientes, modelos, consumos e status.

O backup inclui todos os dados salvos no sistema. A sessão de quem está conectado não é exportada por segurança.

Restauração

Restaurar Backup

Selecione um backup único completo. Mesclar adiciona registros e configurações ausentes sem apagar os dados atuais. Substituir tudo troca o conteúdo atual pelo backup.

Atenção: Substituir apaga os dados atuais e carrega o conteúdo do backup.
